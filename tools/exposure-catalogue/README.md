# HE²AT Environmental Exposure Catalogue

**Live:** <https://portal.placealert.org/heat-catalogue/>

Open catalogue for exploring 35+ environmental exposure variables relevant to the health of mothers and newborns across Sub-Saharan Africa. Environmental data only; personal health information is excluded.

**Stack:** Static front-end, DuckDB

## Key files

- `index.html`
- `setup_he2at_db.py`
