# Courses

Teaching material from the lab's free, certificate-bearing courses on geospatial data science for climate, environment and health.

| Folder | What it contains |
|---|---|
| [`geoai-workshop`](geoai-workshop) | Notebooks for the GeoAI for Climate, Environment & Health course: spatial health data, Earth Engine extraction, environmental datasets, spatial joins and exposure timelines |
| [`workshop`](workshop) | Workshop sources and release notebooks, extraction scripts and facilitator guide |

## Notes

- Notebook **outputs are cleared**, so run them to see results.
- The course is built around Zimbabwe DHS 2015 birth records, which are **not** included. DHS data must be requested from the DHS Program. Learners on the live course receive access through the course platform.
- Earth Engine cells need your own Google Earth Engine project.
- Course pages and enrolment live on the websites in [`../websites`](../websites).
