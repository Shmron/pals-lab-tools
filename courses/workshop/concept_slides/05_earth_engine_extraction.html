Important simplification: our synthetic exposure grid gives NDVI a daily value for teaching convenience. Real MODIS NDVI updates every 16 days — if you build a real study, you'll need to interpolate or forward-fill between composites, not assume daily granularity.

Concept: two ways to extract from Earth Engine

In-notebook (small jobs)

  • Authenticate, run a short extraction directly in Python
  • Good for a handful of points/dates, quick checks
  • Optional in this course — skip if EE isn't configured, nothing downstream depends on it

Code Editor batch job (real studies)

  • Upload your point locations as a FeatureCollection (CSV → Assets → Table)
  • Sample the image collection at every point, every date, in one server-side job
  • Export results to Google Drive — practical for thousands of locations
Design principle carried through the whole course: the EE demo cells are explicitly non-blocking — if the venue's internet fails or quota is exhausted, the notebook prints a skip message and every later cell still runs against the pre-generated exposure_grid.csv.
