Reading the gap

Interpolation (~0.80 pooled) is the optimistic bound — nearby-station leakage and climatology help. Spatial-block extrapolation (~0.35) is the honest deployment number. The gap is a monitoring-density problem, not a features problem: 7 activated predictors moved sparse Uganda +0.08 ρ but dense countries ~0.

Cross-country transfer — zero-shot fails, adaptation recoversρ at target country
Deployment recipe

1. Never ship a foreign model zero-shot — rank skill collapses (ρ ≤ 0.26).

2. A small in-country monitor campaign + adaptation recovers most skill (Gambia 0.08→0.85; Mozambique 0.24→0.69; Kenya 0.18→0.60; Uganda 0.26→0.34).

3. South Africa (n≈33 usable cells) is below the adaptation floor — grow the network first.

Implication: new-country rollout = deploy pipeline + seed monitors + adapt, in that order.

What CHEAQI-PEI is

A relationship-based geospatial composite: we learn covariate→PM2.5 relationships at monitored cells (satellite AOD, land use, meteorology, terrain, emissions proxies — 32 predictors), predict wall-to-wall on a 100 m grid, and map predictions onto a bounded 0–1 Personal Exposure Indicator.

Data: dense-spatial personal monitors (Gambia, Kenya, Mozambique), SAAQIS reference stations (South Africa), AirQo dense-temporal stations (Uganda) — 7,132 labelled 100 m cells.

PEI forms: absolute clip(s/log10(501), 0, 1) — ceiling justified by Saharan-dust episodes reaching ~800 µg/m³ in Gambia — and a fixed-reference ECDF form (bounded, full-range, cross-country comparable, preserves ρ/R²).

Serving: the trained model is exported to an ee.Classifier and evaluated inside Google Earth Engine; this dashboard, QGIS, and any web map consume the same XYZ tile URL — no raster downloads.

Validation framework

Four regimes, always reported together: interpolation (leave-locations-out), extrapolation (spatial blocks), cross-country transfer (zero-shot vs adapted), seasonal. Confidence intervals are spatial-block bootstrap (~4× wider than naive iid — we report the wide ones).

Conventions

log10(1+x) everywhere · per-country reporting · colour maps: Fabio Crameri's Scientific colour maps (batlow / vik / romaO / batlowS / oslo) — perceptually uniform, CVD-safe (Crameri 2018, doi:10.5281/zenodo.1243862).
