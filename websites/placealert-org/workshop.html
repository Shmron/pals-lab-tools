About this workshop

Climate change is already affecting human health in measurable ways. This workshop introduces young surveyors and geomatics professionals to the use of health data, Earth observation products, and GeoAI workflows in climate and health applications.

Participants work through six Jupyter notebooks — following the WorldQuant University format with concept notes, worked examples, and graded exercises — progressing from basic spatial health data to a natural-language AI interface over a real environmental database.

Python Jupyter Notebooks Spatial Join Earth Engine DuckDB GeoAI / NL-to-SQL Climate Health Pregnancy Cohort

How to access the course

Option A — PALSlab Hub (recommended, no install)

  1. Request access Submit a short access request at portal.placealert.org/duckrequest/request. Provide your name, email, institution, and intended hub username. The workshop team approves requests — do this before 25 June and you will receive your login details.
  2. Log in and open the setup notebook After logging in you will see JupyterLab. In the file browser on the left, navigate to PALS → GeoAI_Workshop and open 00_Start_Here.ipynb.
  3. Run the setup cell Run the single cell in 00_Start_Here.ipynb. It copies the workshop notebooks and data to your personal GeoAI_Workshop/ folder — takes about 10 seconds.
  4. Open notebook 01 and begin Navigate to your GeoAI_Workshop/ folder and open 01_spatial_health_data.ipynb. Work through notebooks 01 → 06 in order. Run all cells top-to-bottom; 🧪 YOUR TURN cells ask you to write code and ✔ cells give instant feedback.

Option B — Run locally (if offline or preferred)

Download the materials below, install Python if needed, and run on your own laptop.

  Download zip (17 MB)

Extract the zip, then pip install duckdb ipywidgets scipy, and open 01_spatial_health_data.ipynb with Jupyter.

On the day (25 June, workshop LAN): Notebook 06 includes a live GeoAI interface that connects to the Place Alert Labs server automatically — no extra setup needed whether you use the hub or a local laptop.

Prerequisites

  • Basic Python familiarity (read a CSV, print a variable) — no advanced programming required
  • Familiarity with coordinates (latitude, longitude) from your surveying background
  • A laptop or tablet with a modern browser — no Python install needed if using PALSlab Hub (Option A)
  • A PALSlab Hub account — request access at portal.placealert.org/duckrequest/request before 25 June
  • Google Earth Engine account for the optional live demo in Notebook 05 — sign up free here
